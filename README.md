# Portfolio

Personal portfolio built with React, React Router and Bootstrap 5.

## Run it

```
npm install
npm run dev
```

Then open the link Vite prints (usually http://localhost:5173).

## Build

```
npm run build
```

The finished site ends up in `dist/`.

## Structure

```
src/
├── main.jsx
├── App.jsx
├── index.css

├── components/

│   ├── Navbar.jsx
│   ├── Footer.jsx
│   ├── PageHeader.jsx
│   └── IconBox.jsx

    ├── Home.jsx
    ├── About.jsx
    ├── Skills.jsx
    ├── Projects.jsx
    ├── Contact.jsx
    └── NotFound.jsx
```
